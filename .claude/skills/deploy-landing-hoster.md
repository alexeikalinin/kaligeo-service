# Деплой лендингов на hoster.by

Ты — агент, который вручную (через браузер) заменяет продакшн-файлы лендингов `kaligeo.ru` и `kaligeo.by` на статическом хостинге **hoster.by**. Лендинги живут в репозитории в `landing/ru/index.html` и `landing/by/index.html`, но **не деплоятся через Vercel** — только вручную через панель hoster.by. Смотри `CLAUDE.md` → раздел "Лендинги — структура `landing/`".

Используй `mcp__claude-in-chrome__*` инструменты. В начале сессии обязательно вызови сначала skill `claude-in-chrome`, затем загрузи нужные Chrome-инструменты одним вызовом:

```
ToolSearch: select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__computer,mcp__claude-in-chrome__read_page,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__tabs_close_mcp,mcp__claude-in-chrome__find,mcp__claude-in-chrome__file_upload,mcp__claude-in-chrome__get_page_text
```

## Последовательность действий (проверенная, дословно)

1. `navigate` на `https://www.hoster.by` (редиректит на `hoster.by`) в новой вкладке (`tabs_create_mcp` → `navigate`).
2. Кликнуть иконку профиля вверху справа (у координат ≈ `[1477, 29]` при viewport 1568×717). Если сессия жива — сразу открывается меню с email пользователя (`1alexeikalinin1@gmail.com`); логин не потребовался. Если появится форма логина — остановиться и попросить пользователя войти самому (пароль не вводить).
3. В меню нажать **«Мои услуги»** → открывается `cp.hoster.by/home` (новая вкладка). Там видно обе услуги (`kaligeo.by`, `kaligeo.ru`) со статусом **«Истекает»** — это норма, у обеих оплата действует до 21.10.2026 (дата на момент проверки), НЕ повод оплачивать/продлевать самостоятельно.
4. В левом сайдбаре нажать **«Хостинг»** → список услуг с колонками ID/Тариф/Услуга/Оплачен до. Подтверждённые ID: `217638` = kaligeo.by, `207878` = kaligeo.ru.
5. В строке нужного ID нажать **«Управление»** (справа) → открывается `cp.hoster.by/hosting/<ID>/admin` с данными доступа (FTP-сервер, IP, порт SSH и т.д.).
6. Внизу карточки нажать кнопку **«Войти в панель управления»** → открывается **новая вкладка** с ISPmanager (`https://vh<N>.hoster.by:1500/ispmgr#...`). Она может открыться сразу на разделе **«Сайты»** или прямо на **«Менеджер файлов»** нужного сайта (так было при проверке — не полагайся, что придётся кликать «Сайты» вручную, просто проверь скриншотом, где оказался).
7. Если попал в «Сайты»: найти строку с доменом, нажать **три точки** справа → **«Файлы сайта»** → откроется менеджер файлов на `/www/<domain>/`.
8. В менеджере файлов видно `index.html` в корне (~200 KB) среди других файлов (`favicon.svg`, `og-image.png`, `robots.txt`, `sitemap.xml`, папка `logos/`, `blog/`, `privacy.html`). **Не трогай остальные файлы.**
9. Нажать **«Загрузить»** в тулбаре менеджера файлов → справа открывается панель **«Загрузить файл»** с drag-drop зоной и ссылкой **«Выбрать файл»**.
10. Не кликать «Выбрать файл» напрямую (открыло бы системный диалог) — вместо этого найти input через `find` с запросом вида `"Выбрать файл (file input) inside Загрузить файл dialog"`, он возвращает ref с `type="file"`. Загрузить через `mcp__claude-in-chrome__file_upload` с абсолютным путём:
    - для kaligeo.by → `landing/by/index.html`
    - для kaligeo.ru → `landing/ru/index.html`
11. После выбора файла панель покажет его имя и размер — нажать кнопку **«Загрузить»** под ней.
12. Появится предупреждение **«В папке уже есть файл с таким же именем: Заменить / Сохранить / Пропустить»** — всегда нажимать **«Заменить»**.
13. Панель покажет прогресс-бар и статус **«Загрузка завершена»** с итоговым размером файла — это подтверждение успеха.
14. Закрыть панель загрузки (крестик в углу).
15. Открыть проверочную вкладку на `https://kaligeo.<by|ru>/?nocache=<любой токен>` и вызвать `get_page_text` (или скриншот) — убедиться, что title и текст соответствуют новому контенту, прежде чем отчитаться пользователю.
16. Закрыть все временные вкладки, которые создавал (`tabs_close_mcp` на каждую).
17. Повторить шаги 4–16 для второго домена, если нужно обновить оба лендинга.

## Правила безопасности и осторожности

- **Не удаляй** никаких других файлов в файловом менеджере сайта — только заменяй `index.html`.
- Если панель просит подтвердить перезапись/удаление старого файла — это ожидаемо и безопасно, подтверждай.
- Если встретится модальное окно/alert браузера (`confirm`/`alert`) — не кликай слепо, следуй общим правилам избежания диалогов из инструкций по claude-in-chrome (алерты блокируют дальнейшие команды).
- Если для входа в личный кабинет требуется 2FA/капча — остановись и попроси пользователя пройти этот шаг вручную, затем продолжи.
- Перед загрузкой файла всегда используй актуальную версию из репозитория (`landing/ru/index.html` / `landing/by/index.html`) на диске — не редактируй файл "на лету" в процессе деплоя.
- Если ID услуги/структура панели изменились и шаги 3–5 не совпадают с текущим интерфейсом — исследуй страницу (`read_page`/`get_page_text`) и адаптируйся, не гадай вслепую больше 2-3 попыток; если не получается — остановись и спроси пользователя.
